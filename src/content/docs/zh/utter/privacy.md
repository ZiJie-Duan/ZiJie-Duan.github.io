Utter 是由 {{owner}}（个人开发者，以下称「我们」）开发的 iOS 键盘与语音输入应用。本政策说明 Utter 会处理哪些信息、为什么处理、发送给谁，以及你如何控制它们。

> **简要说明**
>
> - 键盘打字完全在你的手机上处理，不会上传。
> - 只有在你使用语音输入时，录音和与这次输入相关的少量文字才会发送给阿里云百炼，用于识别和整理。
> - 我们没有自己的服务器，不接收、不存储、不出售你的录音或文字，也不做广告追踪或数据分析。

## 1. 键盘打字

- 拼音、英文输入和纠错都在你的设备上完成，使用应用自带的词库与模型。你键入的内容不会被发送到任何地方。
- 为了让打字更准，键盘会在本机记住：你点按每个键的位置习惯、你常用的英文单词、你在纠错时选择保留的写法。这些数据只保存在你的设备上。
- 键盘会读取 iOS 提供的「文本替换」和联系人姓名（系统补充词库），仅用于在本机纠错。
- iOS 要求开启「完全访问」后，键盘才能与 Utter 应用共享数据、使用语音输入。开启后，Utter 也不会上传你键入的内容。

## 2. 语音输入

### 何时录音

开启「语音」后，Utter 应用会让麦克风保持就绪，以便你在键盘上随时开始说话。两次说话之间，Utter 的麦克风输入处于静音状态，不采集任何声音。只有从你点下语音按钮到结束的这段声音会被录制。

### 发送了什么、发给谁

语音识别和文字整理由阿里云百炼（Alibaba Cloud Model Studio，又称 DashScope）完成，默认使用其新加坡区域（国际站）。每次语音输入时，你的设备会直接向阿里云发送：

| 内容 | 用途 |
|---|---|
| 这段录音（实时流式发送；网络不佳时以压缩音频分段发送） | 语音识别 |
| 输入框中光标前的文字（最多 2000 字），以及你继续上次录音时之前已识别的文字 | 作为上下文，提高识别准确度 |
| 你在设置中填写的热词和「专用名词表」 | 提高专有名词的识别和书写准确度 |
| 识别出的文字（开启「整理语音文字」时） | 删除口头禅和重复、修正错别字和标点、整理排版 |
| 说话过程中识别出的文字（开启「说话时显示要点」时） | 生成要点提示 |

这些请求使用应用中配置的 API Key，直接从你的设备发送到阿里云，不经过我们。我们不会接收、存储或查看你的录音和文字。阿里云对这些数据的处理适用其[隐私政策](https://www.alibabacloud.com/help/en/legal/latest/alibaba-cloud-international-website-privacy-policy)和服务条款。

### 在你设备上保存的内容

- **未完成的录音**：为了防止应用崩溃、键盘被关闭或网络中断导致内容丢失，录音和已识别的文字会暂存在设备上的 Utter 应用存储中。文字成功输入后，对应的录音会被自动删除。没能完成的录音最多保留最近 5 条，键盘会提示你「继续上次录音」；你选择放弃时，已识别的文字会存入应用内的收件箱，录音随即删除。
- **收件箱**：你选择存入收件箱的文字保存在本机。
- **设置**：热词、专用名词表、各项开关保存在本机。API Key 保存在 iOS 钥匙串中，仅用于向阿里云发起请求。

## 3. 诊断日志

Utter 会在设备上记录运行日志，例如耗时、错误、内存占用和请求的数量与大小，用于排查问题。日志**不包含**你输入或说出的内容，只保存在你的设备上；每个日志文件最多约 1 MB，旧的记录会被自动覆盖。除非你主动分享给我们，我们无法获得这些日志。

## 4. 应用更新

Utter 使用 Expo 的更新服务（EAS Update）检查和下载应用内容更新。检查更新时，你的设备会向 Expo 的服务器发送应用版本、运行时版本、平台等技术信息，以及网络请求本身附带的 IP 地址。Expo 按其[隐私政策](https://expo.dev/privacy)处理这些信息。

## 5. TestFlight 测试

参加 Beta 测试时，Apple 会按 TestFlight 的条款收集崩溃报告、安装与使用时长等信息并提供给开发者；你通过 TestFlight 提交的反馈（包括截图和文字）也会发送给开发者。详见 Apple 的 TestFlight 条款。

## 6. 我们不做的事

- 不需要注册账号，不收集你的姓名、电话、邮箱等身份信息。
- 不出售、不出租你的任何信息，也不将其用于广告或营销。
- 不使用第三方广告或数据分析 SDK，不跨应用、跨网站跟踪你。

## 7. 权限

- **麦克风**：用于语音输入。
- **键盘「完全访问」**：用于键盘与 Utter 应用之间共享语音状态、上下文和识别结果。

你可以随时在 iOS「设置」中关闭这些权限，关闭后相应功能将无法使用。

## 8. 删除你的数据

- 删除 Utter 应用会删除它在你设备上保存的全部数据，包括暂存的录音、收件箱、设置和打字习惯数据。
- 已发送给阿里云的数据按阿里云的政策处理，你可以依其政策行使相应权利。
- 如有其他疑问或请求，请联系我们。

## 9. 儿童

Utter 不面向儿童设计。我们不会有意收集任何人的个人信息，也不会有意向儿童提供服务。

如果本政策有重要变化，我们会更新本页面并修改上方的「最后更新」日期；必要时会在应用内提示。
